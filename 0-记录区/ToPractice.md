  - 过关标准：能把「有工具 / 无工具」两套话术合并进一个模板文件。

## 第七章 · 记忆系统

- [ ] **跑通一次「写入 → 检索 → 注入」闭环**
  - 用 Chroma（嵌入式、零配置）存一批历史摘要，按 query 检索 Top-K 注入 Prompt。
  - 重点不是跑通，是**观察召回噪声**：故意把 K 调到 10，看上下文怎么被污染。
  - 参考：[kb/20 §一、§四](../1-知识库/20-Agent记忆系统.md)

- [ ] **给召回打分加上时间衰减**
  - 实现 `recall_score = 相似度×w1 + e^(-λΔt)×w2 + log(1+成功召回次数)×w3`，对比"只看相似度"时的召回结果差异。
  - 参考：[kb/20 §三](../1-知识库/20-Agent记忆系统.md)
