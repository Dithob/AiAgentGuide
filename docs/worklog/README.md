# Agent 工作记录

> **这里放的是「Agent 干过什么」，不是给人读的项目说明。**
> 项目说明在 [`README.md`](../../README.md)，AI 协作契约在 [`AGENTS.md`](../../AGENTS.md)。

## 为什么单独放

以前这些内容写在 `README.md` 里，导致「给人看的」和「给 AI 看的 / AI 干的」混在一起：
人打开 README 只想看"这项目怎么用"，却要翻过几屏批次流水账。

现在三分：

| 给谁 | 放哪 |
| :--- | :--- |
| 人 | `README.md`、`index.html`、各笔记目录 |
| AI 协作契约 | `AGENTS.md` |
| **Agent 干过的活（本目录）** | `docs/worklog/` |

## 命名与追加约定

- 文件名：`YYYY-MM-DD-主题.md`（`2026-09-18-ch10-12.md`）
- 一批整理 = 一个文件，**只追加不改写**（历史不美化）
- 每份记录写清楚：记号落在哪、新增了什么、数量变化（多少题 / 多少条）
- 最新一批同时更新 [`../progress.md`](../progress.md) 的进度快照
