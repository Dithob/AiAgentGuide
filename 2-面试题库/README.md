# 面试题库 · 方法与索引

> 定位：教程给的是**选择题**，但面试**不发选项**。
> 所以这个文件夹的真正任务不是"收集题目"，而是**把选择题改造成面试官会问的开放题**。
> 建立日期：2026-09-13

---

## 一、为什么"收集选择题"几乎没用

| 问题 | 后果 |
| :--- | :--- |
| 有选项 → 是**再认**（recognition） | 看到正确答案能选出来，脱离选项就说不出，面试直接崩 |
| 选项本身给了提示 | 干扰项帮你排除了 3/4 的空间，难度被严重稀释 |
| 只考一个点 | 面试是**连环追问**：答对定义后立刻问机制、问工程、问权衡 |
| 覆盖面错觉 | 刷完 42 题感觉会了，其实只是"认得"而已 |

**正确的用法**：选择题当**体检表**——用它定位"哪个知识点我只是认得、讲不出来"，然后针对性地做开放题训练。

---

## 二、选择题 → 开放题：六种转换手法

> 拿到任何一道选择题，按下面六种手法依次"过一遍"，就能榨出 3~6 道真实的面试题。

| 手法 | 动作 | 模板句式 | 难度提升 |
| :--- | :--- | :--- | :--- |
| **A 去选项化** | 把"以下哪个是×"改成直接提问 | "请说明 × 是什么 / 为什么" | ★ |
| **B 追问原理** | 加 Why：为什么是这样设计？ | "底层机制是什么？为什么这么做？" | ★★ |
| **C 落到工程** | 加 How：实际项目怎么做？ | "你在项目里怎么落地？有没有具体配置/代码？" | ★★★ |
| **D 加边界权衡** | 加 Trade-off：什么时候不适用？代价是什么？ | "什么场景下这个方法会失效？代价是什么？" | ★★★ |
| **E 干扰项变陷阱** | 错误选项通常对应**真实误区** → 做成纠错题 | "有人说 ××，你怎么看？" | ★★ |
| **F 反向假设** | 改条件会怎样？ | "如果把 × 换成 ×，结果会变成什么？" | ★★★★ |

## 三、四级深度（面试官真实递进路径）

| 层级 | 问什么 | 答不上来的含义 |
| :--- | :--- | :--- |
| **L1 定义** | 是什么？ | 硬伤，直接减分 |
| **L2 机制** | 为什么？底层怎么做？ | 说明是背的，不是懂的 |
| **L3 应用** | 工程上怎么用？怎么落地？ | 说明没有实战，只读过书 |
| **L4 设计/权衡** | 什么场景不适用？你会怎么选？代价是什么？ | 这是区分"会背"和"能干活"的分水岭 |

**训练目标**：每个核心知识点，至少能答到 **L3**；自己最熟的三五个知识点要能答到 **L4**。

## 四、实战示范：一道选择题如何衍生出 5 道面试题

**原题（ch01-Q26 · 单选）**
> Prompt Caching 命中时，输入 token 成本大约降低多少？　`A` 约 50%　`B` 约 70%　`C` 约 90%　`D` 100%
> ✅ 答案：C

| 手法 | 衍生出的面试题 |
| :--- | :--- |
| A 去选项化 | Prompt Caching 是什么？它缓存的是什么？ |
| B 追问原理 | 为什么"前缀完全相同"才能命中？一字之差为什么就失效？ |
| C 落到工程 | 你会怎么设计 Prompt 结构来最大化缓存命中率？ |
| D 边界权衡 | 什么情况下缓存一定命中不了？这时你会怎么办？ |
| E 干扰项陷阱 | 有人说"流式输出可以省钱"，对吗？（错误选项对应的真实误区） |
| F 反向假设 | 如果缓存命中的是中间段而不是前缀，设计上会有什么不同？ |

→ 整理进 `02-开放题-口述版.md` 的 `O-03`。

````markdown
**参考回答（结构化作答，出声讲一遍）**

**追问链**

1. → （面试官可能接的第二问）
2. → （第三问）
3. → （第四问，通常是工程或权衡）

**雷区**

- ❌ （容易说错的说法）
````

## 七、复习法

| 阶段 | 做法 |
| :--- | :--- |
| **第一遍（当天）** | 做完选择题，只看"错题 + 犹豫题"，把犹豫的标黄 |
| **第二遍（整理时）** | 把标黄的题按六种手法衍生开放题，写进 `02-*` |
| **第三遍（面试前）** | **出声讲**开放题，不看参考答案。卡壳 → 回知识库看对应卡片 |
| **第四遍（模拟）** | 随机抽 5 道，限时 10 分钟连续作答，训练"被追问不慌" |

> 判断标准：**能不能不看任何材料，用 60 秒把一道 L3 题讲完整，并且主动补一句边界。**
