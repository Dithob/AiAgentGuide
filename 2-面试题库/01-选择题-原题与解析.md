## 第一部分 · ch00 序章（15 题）

**1. 单选**　GPT 系列模型中，中文文本的 Token 消耗通常比英文多约多少倍？
`A` 0.5 倍（中文更省） · `B` 1.5~2 倍 · `C` 完全相同 · `D` 约 3 倍（每字固定 3 Token）
✅ **B**｜考点：Token 密度
> 分词器基于 BPE，英文一词 1~2 Token，中文一字 1.5~2 Token。

**2. 单选**　System Prompt 和 User Prompt 的核心区别是什么？
`A` 系统自动生成 vs 用户输入 · `B` 前者设定角色和规则，后者是具体问题 · `C` 只是位置不同 · `D` 只能在 API / 聊天界面用
✅ **B**｜考点：Prompt 分层
> System 全程持续生效，API 中 role 不同（system / user）。

**3. 单选**　Embedding 向量化的主要目的是什么？
`A` 压缩文本省存储 · `B` 转数值向量使语义相近者距离更近 · `C` 加密隐私 · `D` 翻译成机器语言
✅ **B**｜考点：Embedding 本质
> 语义搜索 / 推荐 / RAG 的基础，用余弦相似度量化。

**4. 单选**　Function Calling 中 LLM 的角色是什么？
`A` 直接执行函数返回结果 · `B` 输出结构化调用参数，由外部系统执行 · `C` 只能调用预置函数 · `D` 编译函数
✅ **B**｜考点：只决定不执行
> LLM 不执行任何代码，只生成调用指令。

**5. 单选**　以下哪个模型的开源协议允许商业使用？
`A` GPT-4o · `B` Claude Sonnet · `C` Llama 3（Meta 开源，有商业限制） · `D` Gemini Ultra
✅ **C**｜考点：开源许可
> Llama 3 允许商用但有月活限制（7 亿）；其余均为闭源。

**6. 多选**　以下哪些是 Chain-of-Thought 的优势？
`A` 提升复杂推理准确率 · `B` 减少 Token 消耗降成本 · `C` 推理过程可追溯便于调试 · `D` 适用于所有任务 · `E` 可分步解决数学应用题
✅ **A、C、E**｜考点：CoT 的收益与代价
> CoT 反而**增加** Token 消耗；对简单问答无益甚至有害。

**7. 多选**　关于上下文窗口，以下说法正确的是？
`A` 窗口越大理解能力一定越强 · `B` 满了可通过摘要压缩历史 · `C` GPT-4o 最大支持 128K · `D` 窗口内信息一定能完美记住 · `E` Claude 3.5 Sonnet 支持 200K
✅ **B、C、E**｜考点：窗口的三个误区
> 窗口大小 ≠ 理解力；存在 Lost in the Middle。

**8. 多选**　以下哪些属于 Prompt Engineering 的高级技巧？
`A` Few-Shot · `B` Role Prompting · `C` Gradient Descent · `D` Self-Consistency · `E` Backpropagation
✅ **A、B、D**｜考点：Prompt 技巧 vs 训练算法（高频干扰项）
> 梯度下降、反向传播是**训练阶段**的优化算法。

**9. 多选**　选择关于 Token 计费正确的说法：
`A` Output Token 通常比 Input 贵 3~4 倍 · `B` 与模型版本无关价格统一 · `C` 缓存命中的 Input 可享折扣 · `D` 不同模型价格差异可达 10 倍以上 · `E` 只按字符数计算
✅ **A、C、D**｜考点：计费规则
> 按**分词**计算而非字符数；价格随模型差异巨大。

**10. 多选**　以下哪些是主流的 Embedding 模型？
`A` text-embedding-3-small · `B` BGE（智源） · `C` ResNet-50 · `D` text2vec-large-chinese · `E` YOLOv8
✅ **A、B、D**｜考点：模型识别
> ResNet 是图像分类、YOLO 是目标检测，均非 Embedding。

**11. 单选**　AI 从 ChatBot 进化到第三代（2024-2026），解锁的核心能力是什么？
`A` 生成文本 · `B` 调用外部 API · `C` 自主规划多步任务、循环调用工具、自我纠错 · `D` 基于训练数据回答
✅ **C**｜考点：三代进化
> 第三代（ReAct）的跃迁是自主规划 + 循环执行 + 自我纠错。

**12. 单选**　以下哪个能力是「第一代纯聊天」AI 完全不具备的？
`A` 写文章 · `B` 翻译 · `C` 查实时天气 · `D` 回答通识问题
✅ **C**｜考点：实时数据能力
> 查实时天气需要工具调用，第一代只能用训练数据。

**13. 单选**　Agent 要完成「帮用户订机票」至少需要哪些能力组合？
`A` 仅文本生成 · `B` 文本生成 + 一次 API 调用 · `C` 感知 + 决策 + 工具调用 + 循环观察 + 反馈 · `D` 仅 Function Calling
✅ **C**｜考点：多步任务需要闭环
> 查航班→比价→确认→下单，单次调用无法胜任。

**14. 多选**　以下哪些是 Agent 区别于 ChatBot 的本质特征？
`A` 能自主决定下一步做什么 · `B` 拥有工具调用能力 · `C` 能基于训练数据回答问题 · `D` 能通过循环处理多步任务
✅ **A、B、D**｜考点：区分点识别
> `C` 不是区分点——ChatBot 也能基于训练数据回答。

**15. 多选**　关于 Agent 的适用场景，以下说法正确的是？
`A` 需要调用外部工具的任务 · `B` 需要多步决策的任务 · `C` 确定性高、流程固定的任务 · `D` 需要持续反馈和纠错的任务
✅ **A、B、D**｜考点：适用边界
> 确定性高、流程固定的任务用传统程序更高效可靠。

## 第二部分 · ch01 大模型与 Agent 基础（27 题）

**1. 单选**　AI Agent 与传统 Chatbot 的核心区别是什么？
`A` 运行环境不同 · `B` Agent 具备自主规划和工具调用能力 · `C` 模型 vs 规则引擎 · `D` 本质相同
✅ **B**｜考点：Agent 本质
> 感知→制定计划→调用工具→观察结果→调整策略，形成闭环。

**2. 单选**　Agentic Loop 的标准流程顺序是？
`A` 行动→感知→规划→观察 · `B` 感知→行动→规划→反思 · `C` 感知→规划→行动→观察→反思 · `D` 规划→感知→观察→行动
✅ **C**｜考点：闭环顺序（5 步）

**3. 单选**　以下哪个不是 AI Agent 的核心组件？
`A` LLM · `B` Memory · `C` Tools · `D` GPU
✅ **D**｜考点：逻辑组件 vs 硬件资源
> 核心组件 = LLM / Memory / Tools / Planning。

**4. 单选**　AutoGPT 被认为是 Agent 发展史上的里程碑，主要因为？
`A` 第一个基于 GPT-4 的应用 · `B` 首次展示自主分解任务、上网搜索、执行代码的闭环 · `C` 代码量最大 · `D` OpenAI 官方产品
✅ **B**｜考点：Agent 发展史
> 2023 年开源，首次向公众验证了 Agent 范式可行性。

**5. 单选**　Agent 的自主决策能力主要体现在？
`A` 自动选择调用哪个工具完成任务 · `B` 自动关闭浏览器标签 · `C` 自动升级模型版本 · `D` 自动购买 GPU
✅ **A**｜考点：自主决策 = LLM 推理驱动的动态选择

**6. 多选**　以下哪些是 AI Agent 的典型应用场景？
`A` 自动化代码审查和 Bug 修复 · `B` 智能客服自动回复常见问题 · `C` 自主上网搜索并总结研究报告 · `D` 批量处理 Excel 并生成图表 · `E` 自动管理服务器监控和告警
✅ **A、C、D、E**｜考点：适用边界
> `B` 偏传统 Chatbot（固定问答库），除非要调工具查订单。

**7. 多选**　以下哪些是 Agent 相对于纯 LLM 的优势？
`A` 能获取实时信息 · `B` 能执行代码和操作文件系统 · `C` 推理速度一定更快 · `D` 能与其他 Agent 协作 · `E` 参数量一定更大
✅ **A、B、D**｜考点：Agent 增益与其代价
> Agent 多轮工具调用 → 通常**更慢**；底层模型相同 → 参数量无差异。

**8. 多选**　关于 Devin、Claude Computer Use、OpenAI Operator 三个产品，正确的说法是？
`A` Devin 定位 AI 软件工程师 · `B` Claude Computer Use 能操控图形界面 · `C` OpenAI Operator 是开源本地部署 · `D` 三者都展示了自主操作计算机界面的能力 · `E` 三者都只能通过 API 调用
✅ **A、B、D**｜考点：产品认知

**9. 多选**　以下哪些属于 Agent 的环境交互能力？
`A` API 获取外部数据 · `B` 浏览器自动化 · `C` SSH 执行远程命令 · `D` 传感器感知物理世界 · `E` 修改自身模型权重来学习
✅ **A、B、C、D**｜考点：Agent 不改模型权重
> Agent 用固定 LLM，靠外部记忆与工具扩展能力。

**10. 多选**　Agent 的发展趋势包括？
`A` 单 Agent → 多 Agent 协作 · `B` 纯文本 → 多模态 · `C` 通用 → 垂直领域专业化 · `D` 需人类监督 → 完全自主 · `E` 基于 LLM → 基于规则引擎
✅ **A、B、C**｜考点：趋势判断
> 完全无需人类监督不现实；回退规则引擎不成立。

**11. 单选**　Agent 从用户输入到输出的完整链路包含 8 个步骤，正确顺序是？
`A` 意图识别→任务分类→执行调度→工具选择→工具调用→结果验证→结果整合→输出呈现 · `B` 输入→理解→执行→输出 · `C` 意图→规划→执行→反馈→修正→输出 · `D` 用户提问→LLM 思考→工具调用→返回答案
✅ **A**｜考点：完整链路（简化版会遗漏关键决策节点）

**12. 多选**　意图识别的四种任务类型包括？
`A` 信息查询型 · `B` 任务执行型 · `C` 推理分析型 · `D` 创意生成型
✅ **A、B、C、D**｜考点：任务分类决定执行路径

**13. 多选**　执行调度决策的核心考虑因素包括？
`A` 任务类型 · `B` 执行成本（token/时间） · `C` 失败概率 · `D` 依赖关系
✅ **A、B、C、D**｜考点：调度不是"都交给 LLM"

**14. 单选**　AI Agent 的六大核心模块不包括？
`A` 感知 · `B` 规划 · `C` 编译 · `D` 反思
✅ **C**｜考点：六大模块 = 感知/规划/记忆/工具/执行/反思

**15. 单选**　感知-规划-行动闭环中，规划模块的主要输入是什么？
`A` 只有用户原始指令 · `B` 感知模块的输出 + 记忆系统中的历史信息 · `C` 只有工具执行结果 · `D` 只有外部 API 数据
✅ **B**｜考点：规划的输入来源

**16. 单选**　Agent 的反思模块在什么情况下触发？
`A` 只在任务完成时触发一次 · `B` 工具调用失败或结果不符合预期时 · `C` 只在用户明确要求时 · `D` 每隔固定时间
✅ **B**｜考点：反思触发条件
> 也在陷入循环时触发；高级 Agent 会在关键决策点主动反思。

**17. 单选**　端到端 Agent 架构的主要特点是什么？
`A` 所有功能由一个 LLM 完成，不区分模块 · `B` 两模型分工 · `C` 每模块独立模型 · `D` 不用 LLM

**18. 单选**　在 Agent 架构中，LLM 的角色是什么？
`A` 存储历史对话 · `B` 推理决策和自然语言理解，是大脑 · `C` 执行代码和调用 API · `D` 加密通信

**19. 多选**　以下哪些是模块化 Agent 架构的优势？

**20. 多选**　Agent 的记忆系统通常包含哪些类型？
`A` 短期记忆 · `B` 长期记忆（向量数据库） · `C` 程序性记忆（工具使用流程） · `D` 基因记忆（父 Agent 继承） · `E` 情景记忆

**21. 多选**　关于 Agent 执行模块，正确的说法是？

**23. 多选**　设计 Agent 架构时需要考虑哪些关键因素？
`A` 任务复杂度 · `B` 延迟要求 · `C` 成本预算 · `D` 模型颜色偏好 · `E` 安全要求
✅ **A、B、C、E**｜考点：识别无意义干扰项

**24. 单选**　动态 Prompt 和静态 Prompt 的核心区别是？
`A` 动态每轮重新组装上下文，静态系统指令固定不变 · `B` 动态更长 · `C` 静态更准确 · `D` 没有实质区别

**25. 多选**　上下文窗口中 token 分配策略包括哪些？
`A` 系统指令预留 · `B` 对话历史滚动 · `C` 工具描述动态注入 · `D` 全部 token 留给模型输出

**26. 单选**　Prompt Caching 命中时，输入 token 成本大约降低多少？

**27. 多选**　动态 Prompt 组装中常见的变量来源包括？
