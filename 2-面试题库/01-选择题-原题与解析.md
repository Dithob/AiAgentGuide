## 第一部分 · ch00 序章（15 题）

**1. 单选**　GPT 系列模型中，中文文本的 Token 消耗通常比英文多约多少倍？
`A` 0.5 倍（中文更省） · `B` 1.5~2 倍 · `C` 完全相同 · `D` 约 3 倍（每字固定 3 Token）
✅ **B**｜考点：Token 密度
> 分词器基于 BPE，英文一词 1~2 Token，中文一字 1.5~2 Token。

**2. 单选**　System Prompt 和 User Prompt 的核心区别是什么？
`A` 系统自动生成 vs 用户输入 · `B` 前者设定角色和规则，后者是具体问题 · `C` 只是位置不同 · `D` 只能在 API / 聊天界面用
✅ **B**｜考点：Prompt 分层
> System 全程持续生效，API 中 role 不同（system / user）。

**3. 单选**　Embedding 向量化的主要目的是什么？
`A` 压缩文本省存储 · `B` 转数值向量使语义相近者距离更近 · `C` 加密隐私 · `D` 翻译成机器语言
✅ **B**｜考点：Embedding 本质
> 语义搜索 / 推荐 / RAG 的基础，用余弦相似度量化。

**4. 单选**　Function Calling 中 LLM 的角色是什么？
`A` 直接执行函数返回结果 · `B` 输出结构化调用参数，由外部系统执行 · `C` 只能调用预置函数 · `D` 编译函数
✅ **B**｜考点：只决定不执行
> LLM 不执行任何代码，只生成调用指令。

**5. 单选**　以下哪个模型的开源协议允许商业使用？
`A` GPT-4o · `B` Claude Sonnet · `C` Llama 3（Meta 开源，有商业限制） · `D` Gemini Ultra
✅ **C**｜考点：开源许可
> Llama 3 允许商用但有月活限制（7 亿）；其余均为闭源。

**6. 多选**　以下哪些是 Chain-of-Thought 的优势？
`A` 提升复杂推理准确率 · `B` 减少 Token 消耗降成本 · `C` 推理过程可追溯便于调试 · `D` 适用于所有任务 · `E` 可分步解决数学应用题
✅ **A、C、E**｜考点：CoT 的收益与代价
> CoT 反而**增加** Token 消耗；对简单问答无益甚至有害。

**7. 多选**　关于上下文窗口，以下说法正确的是？
`A` 窗口越大理解能力一定越强 · `B` 满了可通过摘要压缩历史 · `C` GPT-4o 最大支持 128K · `D` 窗口内信息一定能完美记住 · `E` Claude 3.5 Sonnet 支持 200K
✅ **B、C、E**｜考点：窗口的三个误区
> 窗口大小 ≠ 理解力；存在 Lost in the Middle。

**8. 多选**　以下哪些属于 Prompt Engineering 的高级技巧？
`A` Few-Shot · `B` Role Prompting · `C` Gradient Descent · `D` Self-Consistency · `E` Backpropagation
✅ **A、B、D**｜考点：Prompt 技巧 vs 训练算法（高频干扰项）
> 梯度下降、反向传播是**训练阶段**的优化算法。

**9. 多选**　选择关于 Token 计费正确的说法：
`A` Output Token 通常比 Input 贵 3~4 倍 · `B` 与模型版本无关价格统一 · `C` 缓存命中的 Input 可享折扣 · `D` 不同模型价格差异可达 10 倍以上 · `E` 只按字符数计算
✅ **A、C、D**｜考点：计费规则
> 按**分词**计算而非字符数；价格随模型差异巨大。

**10. 多选**　以下哪些是主流的 Embedding 模型？
`A` text-embedding-3-small · `B` BGE（智源） · `C` ResNet-50 · `D` text2vec-large-chinese · `E` YOLOv8
✅ **A、B、D**｜考点：模型识别
> ResNet 是图像分类、YOLO 是目标检测，均非 Embedding。

**11. 单选**　AI 从 ChatBot 进化到第三代（2024-2026），解锁的核心能力是什么？
`A` 生成文本 · `B` 调用外部 API · `C` 自主规划多步任务、循环调用工具、自我纠错 · `D` 基于训练数据回答
✅ **C**｜考点：三代进化
> 第三代（ReAct）的跃迁是自主规划 + 循环执行 + 自我纠错。

**12. 单选**　以下哪个能力是「第一代纯聊天」AI 完全不具备的？
`A` 写文章 · `B` 翻译 · `C` 查实时天气 · `D` 回答通识问题
✅ **C**｜考点：实时数据能力
> 查实时天气需要工具调用，第一代只能用训练数据。

**13. 单选**　Agent 要完成「帮用户订机票」至少需要哪些能力组合？
`A` 仅文本生成 · `B` 文本生成 + 一次 API 调用 · `C` 感知 + 决策 + 工具调用 + 循环观察 + 反馈 · `D` 仅 Function Calling
✅ **C**｜考点：多步任务需要闭环
> 查航班→比价→确认→下单，单次调用无法胜任。

**14. 多选**　以下哪些是 Agent 区别于 ChatBot 的本质特征？
`A` 能自主决定下一步做什么 · `B` 拥有工具调用能力 · `C` 能基于训练数据回答问题 · `D` 能通过循环处理多步任务
✅ **A、B、D**｜考点：区分点识别
> `C` 不是区分点——ChatBot 也能基于训练数据回答。

**15. 多选**　关于 Agent 的适用场景，以下说法正确的是？
`A` 需要调用外部工具的任务 · `B` 需要多步决策的任务 · `C` 确定性高、流程固定的任务 · `D` 需要持续反馈和纠错的任务
✅ **A、B、D**｜考点：适用边界
> 确定性高、流程固定的任务用传统程序更高效可靠。
