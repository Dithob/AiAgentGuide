## 三、使用建议

| 阶段 | 做法 |
| :--- | :--- |
| 学完 ch00/ch01 当天 | 先做 72 道选择题，标记"犹豫题" |
| 周末整理 | 挑 O-01 ~ O-06 出声讲一遍，卡壳的回 `1-知识库/` |
| 学到 ch05 / ch11 / ch13 后 | 回来重讲 O-03 / O-04 / O-11 / O-14，把新学的工程细节补进去 |
| 学到 ch04 ~ ch09 后 | 主攻 **O-31 ~ O-42**——这批是 L3/L4 为主的工程题，**必须出声讲完整**，尤其 O-33 / O-35 / O-37 / O-38 要能主动补一句取舍 |
| 学到 ch10 ~ ch12 后 | 主攻 **O-43 ~ O-58**——Harness / RAG / LLM-Wiki 三块，**RAG 题（O-47~O-55）是面试最高频的一组**，尤其 O-49（排查顺序）、O-51（冲突取舍）、O-52（实时适配）必须讲到 L4 |
| 面试前一周 | 抽 5 题限时连续作答，训练"被追问不慌" |

**这一批的自检标准**：每道题讲完后，问自己一句——**"我有没有说出'什么时候它不适用'？"** 如果说不出，说明还停在 L2（机制），没到 L4（权衡）。
