## 每章照做

1. 复制 `0-记录区/_模板-章节记录.md` → `0-记录区/chXX-标题.md`
2. 读的过程中只填「📖 正文要点」
3. 读完立刻做课后选择题：**只用 `~~X~~ Y` 记错题**（我选 X 错，答案是 Y），对的不用抄
4. 疑问用 `> 疑问：……` 写在对应段落旁边，不现场查
5. **标 `==`**：哪些知识点想加强，用 `==……==` 包住标题或关键词
6. 二次整理：原文归并进知识库；高亮项加 🔆 延伸；错题与衍生题进面试题库
7. 做测验：打开 `3-测验/index.html` → 「🔆 强化专项」→ 再「❌ 错题重做」
8. 复习：30 秒看知识库总表 → 3 分钟出声讲开放题

## 记号速查（你在记录区写 → 会得到什么）

| 你写 | 含义 | 整理后你会得到 |
| :-- | :--- | :--- |
| `==……==` | 想加强的知识点 | 知识库「🔆 强化延伸」+ 新的测验题 |
| `~~A~~ B` | 我选 A（错），答案 B | 面试题库错题表 → 错题根治 → 进测验错题池 |
| 原文摘录 | 你认为重要的原文 | 知识库「📌 你的原文记录」，原样收录 |
| `> 疑问：……` | 你想到的问题 | 知识库「❓ 你的疑问解答」+ 自测题 |

> 整理时机：当天只记不整；一章结束或周末做二次整理。
> 记号怎么被加工，是 AI 的活，规则写在 `AGENTS.md`，日常不用管。

## 测验工具

打开 `3-测验/index.html` 就能用（单文件、离线可用）。

| 参数 | 作用 |
| :--- | :--- |
| 题量 | 本次组多少题 |
| 权重 | 按 `w` 加权抽样（关掉=等概率） |
| 去重 | 同一 `concept` 只取一题（关掉=可重复考点） |
| 种子 | 同一种子 → 同一份卷子（可复现）；「换一批」重生种子 |

**改题**：只改 `3-测验/bank.json`，然后 `npm run sync`（= build → test）。`index.html` 是生成产物，别手改。
完整字段与权重规则见 `AGENTS.md`。

## 多端同步（换设备不丢错题）

1. 测验页工具栏 → **☁️ 同步** → 展开面板
2. GitHub 生成 Personal access token，**只勾 `gist` 一项**
3. 粘进面板 → 点「连接」；每台设备填同一个 token 即可互通

细节见 [`docs/sync.md`](docs/sync.md)。⚠️ token 只存在你的浏览器里，务必只给 `gist` 权限。
