## ⚡ TL;DR（先看这三行，下面正文是参考资料）

- **一句话**：预训练学知识（占 99%+ 算力）→ SFT 学格式 → RLHF/DPO 学偏好，**三段不可互相替代**。

## 🎯 30 秒结论

1. 三阶段流水线：**预训练（学知识）→ SFT（学格式）→ RLHF/DPO（学偏好）**。
2. 预训练占 **99% 以上算力**，用万亿级无标注文本做 Next Token Prediction，产出**基座模型**（会续写、不会对话）。
3. SFT 用几万条"指令-回答对"教模型**怎么回答**；本质是**行为模仿**，教不了新知识。
4. RLHF 用人类偏好训奖励模型再优化；2024 起 **DPO 逐渐取代 PPO**。
5. **SFT 与 RLHF 不可互相替代**：一个教格式，一个教质量。

**Q5：预训练、SFT、RLHF 三个阶段的区别是什么？SFT 和 RLHF 能互相替代吗？**

> **三阶段对比**：
> • **预训练**：用万亿级无标注文本做 Next Token Prediction，学语言和世界知识。产出基座模型（会续写但不会对话）。算力消耗 99%。
> • **SFT**：用几万条指令-回答对微调，学对话格式和指令遵循。产出对话模型（能对话但质量有限）。
> • **RLHF/DPO**：用人类偏好数据优化，学回答质量和安全对齐。产出最终模型（安全、有用、诚实）。
>
> **不能互相替代**。SFT 和 RLHF 解决不同问题：SFT 教模型"**怎么回答**"（格式、风格），学习信号是**逐 Token 模仿**（交叉熵损失）；RLHF 教模型"**回答得更好**"（质量、安全），学习信号是**整体偏好打分**（奖励信号）。SFT 不能教模型区分好回答和差回答（只能模仿），RLHF 不能教模型新知识（只能优化已有能力的表达）。两者互补，缺一不可。

**Q6：什么是 DPO？它和 PPO 有什么区别？为什么 2026 年趋势是 DPO 取代 PPO？**

> **DPO（Direct Preference Optimization，直接偏好优化）**是一种简化版的 RLHF 方法。传统 RLHF 用 PPO 算法，需要先训练一个奖励模型（RM），再用 RM 的打分通过强化学习优化大模型，流程复杂、训练不稳定、超参敏感。
> **DPO 的创新**：跳过 RM 训练，直接用偏好数据（回答 A 比回答 B 好）通过一个简化的目标函数优化模型。数学上证明了 DPO 和 PPO 在最优解上等价，但工程上简单得多。
> **DPO 优势**：① 不需要训练和加载额外的 RM（省一个模型）；② 训练稳定，不需要复杂的 PPO 超参调优；③ 计算成本低，训练速度快。Llama 3、DeepSeek-V3、Qwen 2.5 等主流模型都已转向 DPO 或其变体。PPO 在某些需要在线采样的场景仍有优势，但离线训练场景 DPO 是首选。

## 一、三阶段总览

| 阶段 | 目标 | 数据 | 方法 | 产出 |
| :--- | :--- | :--- | :--- | :--- |
| **① 预训练** Pre-training | 学语言规律与世界知识 | 10~15 万亿 Token 无标注文本 | Next Token Prediction（交叉熵损失） | 基座模型（会续写） |
| **② 监督微调** SFT | 从"续写"变成"对话" | 1 万~10 万条指令-回答对 | 逐 Token 模仿（交叉熵） | 对话模型（能对话） |
| **③ 对齐** RLHF / DPO | 回答得更好、更安全 | 5 万~50 万条偏好对 | 奖励模型 + PPO，或直接 DPO | 最终模型（安全/有用/诚实） |

```
海量无标注文本 ──▶ 基座模型 ──▶ 指令-回答对 ──▶ 对话模型 ──▶ 偏好数据 ──▶ 最终模型
   预训练(99%算力)              SFT                          RLHF / DPO
```

## 二、阶段一：预训练（"读万卷书"）

| 指标 | 典型值 | 说明 |
| :--- | :--- | :--- |
| 训练数据量 | 10~15 万亿 Token | GPT-4 级别约 13T，含网页、书籍、代码、论文 |
| GPU 消耗 | 数万张 H100 × 数月 | GPT-4 预训练估算 ~$63M；Llama 3 70B ~$30M |
| 数据来源 | Common Crawl、书籍、代码库、论文 | 需清洗去重、过滤低质、去除有害信息 |
| 训练目标 | Next Token Prediction | 唯一目标：给定上文，预测下一个 Token 的概率分布 |

**为什么基座模型"不会对话"**：它学的是**续写文本**，不是**回答问题**。你问它"你好"，它可能续写"你好，欢迎来到本店"。

## 三、阶段二：SFT（"学规矩"）

```json
{
  "instruction": "请用一句话解释什么是递归。",
  "input": "",
  "output": "递归是函数在执行过程中调用自身的编程技巧。"
}
```

| 要点 | 说明 |
| :--- | :--- |
| 数据量 | 1 万~10 万条（远小于预训练），但**质量要求极高** |
| 关键论文 | LIMA：仅 1000 条高质量数据就能显著提升对话能力 |
| 本质 | **行为模仿** —— 让模型模仿人类专家的回答方式 |
| 改变的 | 输出格式、风格、指令遵循能力 |
| 不改变的 | 底层知识（那些是预训练学的） |

一句话：**SFT 教模型"什么时候该用什么知识、以什么格式输出"**。

---

## 四、阶段三：RLHF / RLAIF（"对齐人类偏好"）

| 步骤 | 名称 | 做什么 |
| :--- | :--- | :--- |
| Step 1 | 训练奖励模型（RM） | 人类对模型多个回答**排序**，用排序数据训一个"打分器" |
| Step 2 | PPO 强化学习 | 用 RM 给输出打分，通过 PPO 优化模型参数 |
| Step 3 | DPO（替代方案） | 跳过 RM，直接用偏好数据优化；更简单稳定，2024 起主流 |

**RLAIF**：用 AI 代替人类做偏好标注，降低成本。

---

## 五、SFT vs RLHF（高频对比题）

| 维度 | SFT（监督微调） | RLHF（强化学习） |
| :--- | :--- | :--- |
| 训练目标 | 模仿标准答案（"怎么回答"） | 优化人类偏好（"什么回答更好"） |
| 数据形式 | 指令-回答对（**有标准答案**） | 偏好排序（A 比 B 好，**无标准答案**） |
| 学习信号 | 交叉熵损失（逐 Token 对齐） | 奖励信号（整个回答的质量打分） |
| 数据量 | 1 万~10 万条 | 5 万~50 万偏好对 |
| 能解决 | 理解指令、学会对话格式 | 提升质量、安全性、减少幻觉、对齐价值观 |
| **不能解决** | **无法教"什么是好回答"（只能模仿）** | **无法教新知识（只能优化已有能力的表达）** |

> 一句话：**SFT 教模型"怎么回答"，RLHF 教模型"怎么回答得更好"。SFT 是学会说话，RLHF 是说得好听。**

---

## 六、DPO vs PPO

| 维度 | PPO（传统 RLHF） | DPO（Direct Preference Optimization） |
| :--- | :--- | :--- |
| 链路 | 偏好数据 → 训 RM → PPO 强化学习 | 偏好数据 → **直接**优化模型 |
| 额外模型 | 需要额外训练并加载 Reward Model | 不需要 RM |
| 稳定性 | 超参敏感、训练不稳定 | 稳定，超参少 |
| 成本 | 高 | 低，训练快 |
| 数学关系 | — | 已证明与 PPO **最优解等价** |

**趋势（2026）**：Llama 3、DeepSeek-V3、Qwen 2.5 都已转向 DPO 或其变体。
PPO 在需要**在线采样**的场景仍有优势；离线训练场景 DPO 是首选。

---

## ⚠️ 易错点

| 常见错误说法 | 正解 |
| :--- | :--- |
| "用大数据训练"就够了 | 三阶段流水线，数据量和目标完全不同 |
| SFT 和 RLHF 可以互相替代 | 不能。SFT 教格式，RLHF 教质量；且 RLHF 也教不了新知识 |
| SFT 能注入新知识 | 不能。知识来自预训练，SFT 只改行为与格式 |
| RLHF 能教模型新知识 | 不能。它只优化已有能力的表达方式 |
| DPO 完全取代了 PPO | 在线采样场景 PPO 仍有优势；离线训练 DPO 首选 |
| 预训练也能学会对话 | 基座模型只会续写；"会对话"是 SFT 的功劳 |

## 🎤 面试怎么答（口述模板）

> **问：GPT 是怎么训练出来的？**
> "三阶段。第一步预训练，用 10 到 15 万亿 Token 的无标注文本做 Next Token Prediction，让模型学语言规律和世界知识，这一步占 99% 以上的算力，产出的是基座模型——它很博学但不会对话，你问它'你好'它可能续写'欢迎光临'。第二步 SFT，用几万条高质量的指令-回答对做监督微调，让它从'续写'变成'听指令回答'。第三步 RLHF 或者 DPO，用人类的偏好数据优化，让它回答得更好、更安全。一句话：**SFT 教格式，RLHF 教质量**。"

> **追问：SFT 和 RLHF 有什么区别？能替代吗？**
> "不能替代。SFT 的数据是有标准答案的指令-回答对，学习信号是逐 Token 的交叉熵，本质是模仿，解决'怎么回答'；RLHF 的数据是偏好排序，学习信号是整个回答的奖励分，解决'什么回答更好'。SFT 教不了模型区分好回答和差回答，RLHF 也教不了新知识——它只优化已有能力的表达方式。"

> **追问：什么是 DPO？为什么现在都用它？**
> "DPO 是简化版 RLHF。传统方案要先用偏好数据训一个奖励模型，再用 PPO 做强化学习，流程长、不稳定、超参敏感。DPO 跳过奖励模型，直接用偏好数据优化，数学上已经证明和 PPO 的最优解等价，但工程上省一个模型、训练更稳。所以 Llama 3、DeepSeek、Qwen 这些新模型基本都转 DPO 了。需要在线采样的场景 PPO 还是更好。"
