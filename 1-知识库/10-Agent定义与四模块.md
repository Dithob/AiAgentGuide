# 10 · Agent 定义、四模块与三形态光谱

## ⚡ TL;DR（先看这三行，下面正文是参考资料）

- **一句话**：**ChatBot 回答问题，Agent 解决问题**——差别在闭环完不完整、自主性在谁手里。
- **三要点**：①四大核心模块 LLM / 记忆 / 规划 / 工具**缺一不可**；②闭环**感知→决策→行动→反馈**源自 OODA，关键是「反馈回到感知」这条**回边**；③自主性光谱：ChatBot（无自主）→ Copilot（人主导）→ Agent（AI 主导）。
- **追问**：Agent 和 ChatBot 的本质区别是什么？（本条暂无开放题，待补）

---

## 🎯 30 秒结论

1. **AI Agent** = 能感知环境、自主规划、使用工具、采取行动来完成目标的 AI 系统。**ChatBot 回答问题，Agent 解决问题。**
2. 本质区别是**自主性**：ChatBot 被动应答，Agent 主动拆解任务、调工具、多步执行。
3. **四大核心模块**：LLM（大脑）/ 记忆（Memory）/ 规划（Planning）/ 工具（Tools）——**缺一不可**。
4. 核心闭环**感知 → 决策 → 行动 → 反馈**，源自控制论 **OODA 循环**；关键是「反馈回到感知」这条**回边**。
5. **自主性光谱**：ChatBot（无自主）→ Copilot（人机协作，人主导）→ Agent（自主执行，AI 主导）。

---

## 一、ChatBot vs Agent：差别在闭环完不完整

同样的任务「帮我查明天北京的天气」：

| | ChatBot | Agent |
| :--- | :--- | :--- |
| 行为 | "我无法实时查询天气，但你可以…" | `[思考]` → `[工具调用] weather_api("北京","2026-07-02")` → `[观察]` 晴 28°C → 组织回答 |
| 闭环止于 | **生成文本**（告诉你去查） | **改变外部状态**（真的查了，还能顺手设提醒） |
| 角色比喻 | 顾问 | 员工 |

> 一句话：**ChatBot 是"嘴"，Agent 是"手 + 脑"。**

---

## 二、四大核心模块（缺一不可）

| 模块 | 作用 | 缺了会怎样 |
| :--- | :--- | :--- |
| **LLM（大脑）** | 理解意图、推理决策、生成回答 | 没有智力 |
| **记忆 Memory** | 短期（对话上下文）+ 长期（向量库存经验） | 没有连贯性，跨轮就失忆 |
| **规划 Planning** | 把复杂目标拆成可执行的子任务序列 | 只能做简单任务 |
| **工具 Tools** | 调外部 API / 代码执行器 / 数据库 | 无法与外部世界交互 |

> 这与 `01-知识库` 里的「四大能力域（感知/思考/行动/观察）」是**同一件事的两种切法**：
> **能力域按"运行时动作"切**（在循环里干什么），**四模块按"系统组件"切**（由谁来干）。面试被问哪个就答哪个，但别说混。

---

## 三、核心闭环：感知 → 决策 → 行动 → 反馈

```
        感知 ──▶ 决策 ──▶ 行动 ──▶ 反馈
         ▲                              │
         └──────── 回边（关键）─────────┘
```

**为什么"回边"是灵魂**

| 有回边 | 没有回边 |
| :--- | :--- |
| 每次行动后观察结果、调整下一步 → **容错 + 自适应** | 退化成**单向流水线**，遇到意外就卡死 |
| 从"一次性执行"变成"持续修正" | 无法处理开放性任务 |
| 能多轮循环处理复杂任务 | 只能完成预定义流程 |

> 这个闭环源自控制论中的 **OODA 循环**（Observe-Orient-Decide-Act）。后续章节的 **ReAct 模式、反思机制都是这个闭环的演进**。

---

## 四、自主性光谱：ChatBot / Copilot / Agent

| 维度 | ChatBot | Copilot | Agent |
| :--- | :--- | :--- | :--- |
| 核心能力 | 对话回答 | 辅助完成 | **自主完成** |
| 自主性 | 无 | 低（需人引导） | **高（自主规划）** |
| 工具使用 | ✗ | 有限 | ✓ 完整 |
| 记忆能力 | 短期 | 短期 | **短期 + 长期** |
| 决策主导权 | — | **人主导** | **AI 主导，人可监督** |
| 典型产品 | ChatGPT | GitHub Copilot | Devin, AutoGPT |

**记忆口诀**：越往后 AI 自主性越强、人的参与度越低，**但对可靠性和安全性的要求也越高**。
> ⚠️ 别把 Copilot 当成"弱一点的 Agent"——它们的**决策主导权归属不同**，这是本质区别。

---

## ⚠️ 易错点

| 常见错误说法 | 正解 |
| :--- | :--- |
| ChatGPT 是 AI Agent | 不是。它是 ChatBot——只会说，不会动 |
| Agent 用了更贵/更大的模型 | 同一个底层 LLM，差在架构（工具 + 循环 + 记忆） |
| 四模块可以少一两个 | 缺 LLM 没智力，缺记忆没连贯性，缺规划只能做简单任务，缺工具无法交互 |
| 闭环是"感知→决策→行动"三步 | 漏了**反馈**（以及回边）。没有反馈就没有纠错 |
| Copilot 就是自主性低的 Agent | 错。Copilot 是**人主导**，Agent 是 **AI 主导**——决策权归属不同 |
| 闭环执行一次就结束 | 闭环是**循环**的，多轮直到任务完成 |

## 🎤 面试怎么答（口述模板）

> **问：什么是 AI Agent？和 ChatBot 的本质区别是什么？**
> "Agent 是能感知环境、自主规划、使用工具、采取行动来完成目标的系统，它由四个核心模块组成：LLM 做大脑负责推理决策，记忆负责上下文和长期经验，规划负责把复杂目标拆成子任务，工具负责与外部世界交互。和 ChatBot 的本质区别是**自主性**——ChatBot 的闭环止步于生成文本，它能告诉你该去查天气，但查的动作要你来做；Agent 的闭环延伸到了改变外部状态，它真的调了 API、拿到数据、再组织回答。一句话：ChatBot 回答问题，Agent 解决问题。"

> **追问：那它和 Copilot 呢？**
> "它们是自主性光谱上的三个层级：ChatBot 无自主，Copilot 是人机协作、人主导决策，Agent 是自主执行、AI 主导决策但人可监督。最本质的区别在**决策主导权归谁**，不是能力强弱。"
